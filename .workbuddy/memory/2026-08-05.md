## README 测试章节插图可见性修复（legal-doc-rag）
- 问题：上一轮在 README 用相对路径 `docs/images/*.svg` 引用三张概念图，用户在预览器中看不到（相对路径不解析 / 预览器不渲染 SVG）。
- 修复：用 matplotlib（Microsoft YaHei 字体）将三张图重绘为 PNG，并以 base64 **内联**进 README.md（`![...](data:image/png;base64,...)`），不再依赖相对路径或 SVG 渲染。图内文案同步由"还空"改为"已实现"。
- 生成脚本：`scripts/_gen_readme_imgs.py`（可重跑重新生成）。
- 清理：删除已被取代、不再被引用的 3 个旧 SVG 文件；`docs/images/` 现仅留 3 个 PNG 作为文件级备用。
- 经验：README 插图要在 WorkBuddy/VS Code 等多种预览器都可见，**base64 内联 PNG** 比相对路径 SVG 更稳（GitHub 会过滤 data URI，但本地/编辑器都能看）。
