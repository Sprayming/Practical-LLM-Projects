五、两个最常考的考点（面试 / 白板默写必中）

    

      

        
① 租户隔离：怎么"按租户目录落盘"

        
根目录 + tenant_id 拼子目录：uploads/{tid}/ 与 chroma_db/{tid}/ 是互相独立的物理文件夹。安全靠 get_safe_upload_path()（middleware.py:114，tenant_id 只留 [a-zA-Z0-9_-] + 文件名清洗）再加 is_safe_path()（:102）防 ../ 穿越 —— 没有这层，目录隔离反而成漏洞。

      

      

        
② 为什么 hybrid + reranker，而不是纯语义

        
法律术语要精确匹配避免漏检，所以 BM25 关键字 + 向量双路召回（HybridRetriever.retrieve :238）；向量负责"语义相似"，再用 Reranker.rerank()（:42，BAAI/bge-reranker-base Cross-Encoder）精排提精度。真实实现，不可用时优雅降级。
